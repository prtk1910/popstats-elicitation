# popstats-elicitation

Do language models know what they don't know about populations?

We elicit numeric conditional distributions of real socioeconomic quantities
(household income, wage earnings, commute time) from **stealth/ox-alpha**
(via OpenRouter) and score them against weighted quantiles computed from ACS 2023
1-Year PUMS microdata for California and New York.

## Findings (final run)

- Median-level error averages **0.042 gold-IQR units** across 120 scored estimates
  in 40 population cells spanning conditioning depths 0–3.
- Error is **flat in conditioning depth** (depth-0 MAE 0.039 vs depth-2 0.047) and
  flat in cell size (small 0.040 vs large 0.044) — the signature of prior-driven,
  not data-driven, estimation: real sampling error varies by orders of magnitude
  more than the model's implied uncertainty.
- Stated central-90% prediction intervals achieve **85.5% mean coverage** vs nominal
  90%, with per-cell coverage ranging 73.4%–93.8% — decent on average, but no
  evidence the model knows *which* cells are uncertain.
- Zero degenerate responses under strict JSON elicitation.

Full manuscript: `PAPER.md` / `PAPER.docx` (regenerated by `make paper`).

## Reproduce

```bash
cp ../.env.example .env    # or rely on shared root .env (OPENROUTER_API_KEY)
make setup
make test                  # weighting math + population anchors vs published totals
make fetch                 # streams CA+NY PUMS zips (~200MB), reduces to ~6MB parquet
make build
make run                   # 200 elicitation calls, resumable ledger
make paper                 # figures + PAPER.md + PAPER.docx
```

## Layout

- `src/popstats/pums.py` — census.gov streaming downloader + Parquet reduction
- `src/popstats/gold.py` — numpy-accelerated weighted quantiles + bootstrap CIs
- `src/popstats/grid.py` — conditioning-depth cell definitions (depths 0–3)
- `src/popstats/elicit.py` — quantile/interval arms, schema-in-prompt fallback
- `src/popstats/api.py` — OpenRouter client, content-addressed ledger
- `src/popstats/analysis.py` — pinball loss, coverage, figures, manuscript
